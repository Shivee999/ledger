Why this matters

Computers store everything as binary because a circuit is either carrying current or it is not — two states, so base 2. Hexadecimal exists because binary gets unreadable fast: one hex digit stands for exactly four binary digits, so 11111111 becomes FF. That is why colours in web design are written as hex, and why memory addresses are too.
