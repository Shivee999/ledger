What the parts are

PC — program counter holds the address of the next instruction. It is what makes a program move forward.
IR — instruction register holds the instruction currently being worked on, after it is fetched.
MAR / MDR are the address and data registers. MAR says which memory cell to reach for; MDR carries the value travelling to or from it.
ACC — accumulator holds the working value the arithmetic unit operates on.
ALU is the arithmetic and logic unit, the part that actually adds, subtracts and compares.
SimplifiedReal processors overlap these stages through pipelining, run several instructions at once, reorder them, and use caches heavily. This is the teaching model, which is still the right mental starting point.
