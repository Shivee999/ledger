Every dashboard,
one board.

Every dashboard, tracker and command deck built across roughly two months, sorted into six sectors that have nothing to do with each other. Counts below are computed from the list itself, not typed in. Each one lives inside the conversation that produced it — none are standing files, so the action on all of them is rebuild, not download.

What this board is not

  • These are not files. Every dashboard here was rendered inside a chat. Nothing was written to a server, so there is no download link and nothing to host. Opening the chat and rebuilding is the only route to a working copy.
  • Some are genuinely gone. Anything rendered into a temporary sandbox — the HTML exports, the command deck file — reset when that session ended. If it was not downloaded at the time, it exists as a record here and nowhere else.
  • Coverage is keyword-bound. These were found by searching names already known, plus a chat-list screen recording. A dashboard from a chat with a title that matched nothing searched would not appear.
  • The numbers inside them have aged. Progress percentages, costs and pipeline figures were true on the day they were built. Treat any figure recalled from these as stale until re-checked.
