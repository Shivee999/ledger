Read this before you trust the list

  • Artefacts have no individual links. There is no per-artefact URL that can be generated. Stack 01 rows carry genuine public URLs because those things were deployed to GitHub or Netlify. Stack 02 rows link to the conversation — open it and scroll to find the file. Those chat links only open for the account that owns them.
  • The window is shorter than 90 days. The chat-listing tool returned nothing before 1 August 2026. Keyword search reaches further back, so June items are included, but only ones searched for by name. Ventures never searched for may be missing.
  • The live URLs were not opened during compilation. The build sandbox blocks *.github.io and *.netlify.app. Every Stack 01 address is transcribed from session records, not confirmed as serving today.
  • Sandbox files are gone. Rendered MP4s, ZIPs and PNGs were written to temporary sandboxes that reset between sessions. If they were not downloaded at the time, the row is a record that it existed — not a retrievable file.
  • Counts are what was found, not what exists. Treat this as a working index to correct, not a complete audit.
